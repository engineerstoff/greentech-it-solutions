# GreenTech IT Solutions

Official website for **GreenTech IT Solutions**, an IT consulting brand focused on web development, AI automation, networking, cloud solutions, IT support and technical documentation in Ghana.

## Website

GitHub Pages URL: https://engineerstoff.github.io/greentech-it-solutions/

## Deployment

The site is a static HTML/CSS/JavaScript build. Generated website visuals are stored as compact Base64 WebP data files under `assets-data/` and loaded by the browser at runtime. This keeps the repository deployable using GitHub Pages without a server-side backend.

To publish from GitHub Pages, set **Settings → Pages → Deploy from a branch → main → /(root)**.
